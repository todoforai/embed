DO it AI

A button for your site.
Visitors click — their AI agent does the task you wrote.

Write the task in the tag

<script src="https://todofor.ai/embed/embed.js"
  data-todo-prompt="Set up port forwarding on my router
for ports 8000-8080."></script>

Needs a tool or the browser extension? Add
data-todo-requirements="cli:gh,extension:chrome"

↳

Or use a template

<script src="https://todofor.ai/embed/embed.js"
  data-todo-template-id="f5bot-monitoring-setup"></script>

Saved in the template registry —
edit the task later without touching your site.

↳

Match your site's style

todoforai-button {
  --todoai-bg: linear-gradient(135deg, #ff4500, #ff9500);
  --todoai-color: #fff; --todoai-radius: 999px;
}

Plain CSS on your page — label via data-label="...".

↳

Or use your own button

<button data-todo-trigger
  data-todo-prompt="Set up port forwarding...">
  Fix this for me
</button>

Any element, fully yours — we only attach the click.
